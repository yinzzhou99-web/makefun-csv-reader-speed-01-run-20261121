A fast drop-in for csv-reader 1.0.0: solve.js exports run(input), which returns exactly the answer csv-reader gives for a broken CSV text — {columns, rows, errors}, with stray CRs, quote junk, unterminated quotes and ragged rows read by csv-reader's own policy. Where csv-reader walks the text a character at a time, this reader scans for the next special character and slices whole clean spans at once, so identical answers come out in a fraction of the CPU time.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
